Scale and geometry

Which scales can we ignore, which change learning, and which should an optimizer constrain?

  1. 01

    The same network, a different step

    Two identical predictors take different SGD steps. A two-dimensional example exposes the geometry behind effective learning rates.

  2. 02

    What normalization makes invariant

    Trace the scale through LayerNorm, RMSNorm, residual branches, and shared gains before deciding which weight norms can be fixed.

  3. 03

    Weight decay changes the clock

    Derive the radius recurrence and an exact SGD schedule equivalence, then separate those identities from an equilibrium approximation.

  4. 04

    Momentum, rotation, and normalized updates

  5. 05

    Compare worst-case and average activation changes, derive the RMS width factor, and see why a dense layer and an embedding need different rulers.

  6. 06

  14. 14

  15. 15
